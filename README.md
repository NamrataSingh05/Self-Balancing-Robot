# Self-Balancing-Robot
Built a two-wheel self-balancing robot using Arduino Nano, IMU, and encoders. Implemented cascade PID control for stability and integrated Bluetooth-based directional control along with a robotic manipulator.

# Self-Balancing Robot using ESP32

## Overview
A two-wheel self-balancing robot developed using ESP32 and MPU6050.

The robot maintains upright balance using PID and LQR control algorithms.

## Components Used
- ESP32 Dev Board
- MPU6050 IMU
- TB6612FNG Motor Driver
- N20 Encoder Motors
- LiPo Battery

## Features
- Real-time balancing
- PID control
- LQR control
- Encoder feedback
- Yaw stabilization

## Technologies
- Embedded C++
- ESP32
- Control Systems
- Robotics

## Results
The robot successfully balances and recovers from small disturbances while maintaining stability.
